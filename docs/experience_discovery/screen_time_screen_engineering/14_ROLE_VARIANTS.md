## Layout variants

### Observer Overview
Status cards only · “Viewing only” banner · no action row · Requests list read-only.

### Partner Overview
Remaining + pending request badge as hero CTA · no schedule editors · ceiling education link.

### Full Overview
Action row present · editors for cap/schedule/overflow · Lock · Requests · ownership controls absent (no anti-tamper entry).

### Primary Overview
Full + Policy Health deep + Anti-tamper entry + ceiling rule management.

### Child
No parent diagnostics · protected exits emphasized · calm tone.
