## 6. Visual Completion Standard

A screen is incomplete until **both** function and visual UX pass:

- Hierarchy (primary dominate; safety outranks metrics)
- Layout / spacing / density / alignment / safe areas
- Typography (AR wrap, hierarchy, truncation)
- Components (buttons, cards, banners, dialogs, empty/error/loading)
- Interaction (≥48dp, feedback, clear primary action)
- RTL / Arabic (genuine RTL, icon placement, ARB-only strings)
- KEEP + REFINE design language — no parallel design system

**Dashboard:** ORIENT → PRIORITIZE → ACT → DRILL DOWN  
**System home:** What is it? State? Controls? Attention? Next?
