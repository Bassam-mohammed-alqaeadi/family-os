# Learning Global Parity & Differentiation Matrix

> **Status:** Product-readiness evidence
> **Purpose:** Match meaningful global learning expectations while preserving the Family OS advantage: connected family context, guardian support, child dignity, and capability truth.

## 1. Outcome parity matrix

| Learning outcome | Global expectation | Family OS direction | Boundary |
|---|---|---|---|
| Child has a clear next learning action | Lessons, practice, quizzes, tailored next step and continuation across devices. | Child Learn Home and plan show one meaningful next step with truthful availability. | Core; cross-device sync requires future delivery proof. |
| Guardian can support without being a teacher | Parent dashboard connects child, assigns work, follows activity/progress. | Learning Hub gives concise support action, plan, assignment and progress context. | Core; no complex teacher-admin interface required for family use. |
| Assignment lifecycle is reliable | Create, due date, submit, feedback, progress, guardian summary. | Versioned/approved artifact, assignment, delivery, result, guardian/co-guardian visibility. | Core; real remote delivery/grading waits for implementation. |
| Assessment creates learning feedback | Practice, quiz, formative feedback, skill gaps, retry/review. | Constructive child result and guardian support narrative; separate factual result from inferred gap. | Core baseline; advanced auto-grading is capability-gated. |
| Motivation builds habit | Small daily goals, streaks, achievements, celebration. | Recognition and streaks reward effort/progress; no default sibling ranking or financial implication. | Core non-financial loop. |
| Tutor helps learning safely | Step-by-step/Socratic guidance, content context, guardrails, guardian visibility. | Guided tutor, approved context, no-answer policy, safety/feedback/visibility model. | Differentiator; no live model claim before proof. |
| Learning adapts with evidence | Recommendations, mastery path, practice/review loops. | Explainable adaptive plan only after enough skill evidence; “not enough information” is valid. | Differentiator; no opaque learner label. |
| Creator/teacher workflow saves preparation effort | Create assignments, reusable content, feedback and class/guardian communication. | Parent Studio creates/reviews/approves/assigns family learning artifacts. | Family-first differentiator; content ingestion/generation awaits governance. |
| Optional cultural learning has depth | Families expect dignity, choice, and appropriate context. | Quran path is a rich elective within learning, with respectful progress/focus/routine design. | Existing system; speech correction remains capability-gated. |
| Focus supports learning | Routine, reduced distraction, study context. | Focus explicitly joins learning plan, calendar, safety/time rule, device capability, child explanation. | Core cross-pillar advantage. |

## 2. Family OS differentiation

Family OS does not try to become a school LMS first. Its differentiated position is:

1. **Family-level continuity:** learning, safety, tasks, calendar, rewards, focus, and guardian support share one child/family context.
2. **A parent’s practical next action:** guardian views translate activity into one supportive action rather than exposing a teacher-grade console.
3. **Reviewed creation:** Parent Studio creates a safe bridge between the family’s real materials and child learning, with approval before delivery.
4. **Truthful AI:** guided help, source/quality boundaries, and data insufficiency are visible rather than hidden behind “smart” branding.
5. **Respectful growth:** rewards, Quran routines, review, focus, and learning gaps encourage progress without shame or coercion.
6. **Capability clarity:** imported content, camera, speech, media, generation, grading, and sync are shown only when genuinely available.

## 3. Claims Family OS must not make before proof

- “AI always gives the right answer / grades work accurately.”
- “Camera scans any book or solves any question.”
- “Automatically corrects recitation.”
- “All content is verified or appropriate everywhere.”
- “Assignments sync instantly to every child device.”
- “Focus mode blocks all distractions.”
- “A streak or score proves mastery.”
- “Community content is safe” before moderation/provenance/operations exist.

## 4. Global readiness requirements

Before launch/marketing any learning slice, verify language and RTL/LTR quality; age/grade/curriculum/content context; accessibility/accommodations; timezone/calendar/due-date behavior; content rights/attribution/regional availability; child/guardian privacy/support model; actual AI/media/camera/speech capability; and evidence that the family loop creates useful support rather than pressure.
