## Deliberate deletion

`docs/experience_discovery.zip` was removed rather than archived a second time. It was an opaque duplicate containing only a subset of the now-preserved discovery material; Git already provides revision history for the original files.

## Using archived material safely

- Use it to understand prior decisions, evidence or design context.
- Do not copy its phase names, “next” markers, hard stops, verification instructions, scopes or completion claims into current work without reconciling them with [`../CURRENT_EXECUTION_PLAN.md`](../CURRENT_EXECUTION_PLAN.md).
- Links inside an archived pack may describe its original repository layout. They are historical references, not active routing instructions.
