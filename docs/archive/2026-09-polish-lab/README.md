# 🔬 مختبر الصقل — polish-lab
مجلد مستقل عن مجلدات المشروع الأساسية (قرار المالك).

**الآلية:** لكل محطة صقل تُولَّد عينة معزولة تحوي شاشات المحطة فقط، تبدأ من أول شاشة في الرحلة.
نعدّل في العينة حتى يعتمدها المالك ← ثم تُطبَّق التعديلات نفسها على النموذج الأصلي
`family-os/family_os_app.html` (هو المرجع الدائم) ← وتُعاد الفحوص السبعة عليه.

- `make_sample.py` — المولّد الآلي (يقرأ من النموذج الأصلي دائمًا، فالعينة تعكس آخر حالة معتمدة).
- `m1_*.html` … عينات المحطات.
- أي ضغط زر يقود خارج العينة يظهر تنبيهًا لطيفًا بدل الكسر.
