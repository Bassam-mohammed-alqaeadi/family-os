## 1. UX principle

Modes are a **lifestyle overlay control surface**: parents define situational tighten overlays (Sleep, School, Study, Ramadan, Vacation, Family Time, + custom), schedule/activate them through **one unified scheduler**, and see **honest multi-mode composition**.

Children see **active Mode + restriction/grace disclosure** — never Mode admin.  
**Configured Mode ≠ enforced on device** until last-acked policy + verified planes prove it.

IA is organized by **role job**, not Stage-1 FAT-085 filenames.

---

## 2. Role-level mental models

| Role | Job-to-be-done | Product shape |
|---|---|---|
| **Primary Parent** | Author Modes; scope; schedule; activate; ModeException; preview; honesty; audit | Full Modes suite |
| **Co-Parent Full** | Same configure authority as Primary for Modes | Full configure |
| **Co-Parent Partner** | View state + notifications; ticket-authorized activate/deactivate only | Read + limited ops |
| **Co-Parent Observer** | View summary + honesty | Read-only |
| **Child** | Active Mode card; restriction/grace disclosure; SOS/Chat/Quran always | **No** admin |

## 3. Parent Information Architecture

### 3.1 Logical nav (not final chrome)

```
Parent shell
 └─ الأوضاع الذكية / Modes  (family system hub)
     ├─ OVERVIEW ………………… honesty · active stack · upcoming · shortcuts
     ├─ CATALOG
     │    ├─ Built-in Modes (Sleep · School · Study · Ramadan · Vacation · Family Time)
     │    └─ Custom Modes list
     ├─ MODE DETAIL / BUILDER …… identity · scope · overlays · schedule · grace · exceptions
     ├─ SCHEDULER (unified) ……… manual · clock/weekly · seasonal · location-derived
     ├─ ACTIVE STACK …………… multi-mode composition · stricter result
     ├─ EXCEPTIONS ……………… ModeException inbox / editor (Mode overlay only)
     ├─ PREVIEW ………………… preview-before-apply
     ├─ DEVICES / ACK …………… per enrolled child device honesty
     └─ DECISIONS / AUDIT ……… Mode mutations · activations · composition · exceptions

Cross-links (not owned by Modes IA):
 ├─ FS-001 Location …………… geofence edit (Modes consume facts only)
 ├─ FS-002 Web Filtering …… Mode tighten chip · no URL editors here
 ├─ FS-003 App Control ……… Mode tighten chip · no package store editors
 ├─ FS-004 Screen & Camera … Mode tighten chip · no permanent SC editors
 ├─ Screen Time ……………… minutes / grants / wallets (deep link; no ScheduleWindow Mode authority)
 ├─ Instant Device Lock …… above Modes
 ├─ SOS ………………………… ungated
 └─ Notifications …………… Mode activate / conflict / ack stale
```

### 3.2 Capability → IA home

| Capability | Lives in | Notes |
|---|---|---|
| Built-in catalog | CATALOG | Canonical six; no `exams` / `famtime` aliases |
| Custom create/edit | BUILDER | Same entity as built-in |
| Name / icon | BUILDER identity | Required |
| Family-wide vs selected children | BUILDER scope | Explicit multi-select; no silent expand |
| Manual activate/deactivate | OVERVIEW · DETAIL · SCHEDULER | Instant = skip grace |
| Clock / weekly | Unified SCHEDULER | One authority |
| Seasonal / date-range | Unified SCHEDULER | — |
| Location-derived | SCHEDULER + FS-001 fact chip | No geofence editor |
| Multi-mode stack | ACTIVE STACK | Never “only one Mode” UX |
| Composition / stricter | ACTIVE STACK · PREVIEW | Explain intersection |
| ModeException | EXCEPTIONS | ≠ App AE ≠ Grant |
| Preview-before-apply | PREVIEW sheet | Registry spirit |
| Device ack / stale | DEVICES / ACK | Honesty |
| Audit | DECISIONS / AUDIT | Append-only browse |
| ST minutes | **Screen Time** deep link | Forbidden editors |
| ScheduleWindow | **Not exposed** as scheduler | Legacy debt only |

### 3.3 Parent surface stack

| Layer | Content |
|---|---|
| **App bar** | Title · family context · SOS ungated |
| **Honesty strip** | Plane · ack · multi-device · Mode stack count |
| **Active stack strip** | Chips of currently applicable Modes + “Effective: stricter” |
| **Body** | Catalog / detail / scheduler / exceptions / audit |
| **Sheets** | Preview · confirm activate · deactivate · delete · offline queued · conflict explain |
| **Forbidden in body** | URL list editors · package policy store · geofence geometry · ST minute wallets · ScheduleWindow twin · loosen/widen CTAs · invent wake APIs |

## 4. Child Information Architecture

```
Child shell
 └─ Day / status surfaces
     ├─ ACTIVE MODE CARD …… name(s) · restriction summary · grace if any
     ├─ COMPOSITION NOTE …… “Several Modes active — stricter rules apply” (when multi)
     ├─ GRACE BANNER ……… finish-what’s-in-hand (non-cancel)
     ├─ DENY / restriction interstitial (when Mode denies) · source = Mode
     └─ Always: SOS · Required Family Chat · Quran entry
```

**Forbidden child IA:** Mode builder · schedule editor · deactivate Mode · clear grace as policy cancel · reopen blocks.
