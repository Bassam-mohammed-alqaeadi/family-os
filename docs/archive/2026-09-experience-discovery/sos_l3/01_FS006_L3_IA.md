---

## 1. UX principle

SOS is an **emergency incident console**, not a settings toy.

Children: hold → fire → active critical UI → optional false-alarm cancel.  
Parents: honest incident + **separate** delivery facts + respond/escalate/resolve per role.  
**Local incident created ≠ parent notified.**

IA by role job — Stage-1 CHD-005/006 · FAT-018/028 are evidence hosts, not law.

---

## 2. Role mental models

| Role | Job | Shape |
|---|---|---|
| **Primary** | Full control · config · break-glass · evidence · audit | Full suite |
| **Co-Parent Full** | Partner + config + break-glass | Full − Primary-only edge cases none for SOS nuclear |
| **Co-Parent Partner** | Receive · view · ack · respond · escalate · resolve | No config / break-glass |
| **Co-Parent Observer** | Receive · view essential · contact child | **No** ack / escalate / resolve / config / break-glass |
| **Child** | Trigger · active critical · false-alarm cancel | **No** admin / break-glass |

---

## 3. Child IA

```
Child shell (always)
 ├─ SOS ENTRY (FAB / CHD-005) …… always reachable under lock/Mode/ST/expiry
 └─ ACTIVE SOS (CHD-006 class)
      ├─ Incident status
      ├─ Delivery honesty (queued/attempting/… — never fake “sent”)
      ├─ Location honesty (FS-001 attach)
      ├─ Contact parents
      ├─ False-alarm cancel confirm
      └─ Always: Family Chat · Quran · (no entertainment chrome if Panic Quiet)
```

**Forbidden child:** break-glass · ladder admin · trusted-contact edit · evidence admin · escalate config.

---

## 4. Parent IA

```
Parent shell
 └─ SOS / Emergency
     ├─ READINESS ……………… honest capability (OD-21)
     ├─ ACTIVE INCIDENTS ……… console (FAT-018 class)
     │    ├─ Lifecycle state
     │    ├─ Delivery matrix (≠ incident)
     │    ├─ Location honesty → FS-001 deep-link
     │    ├─ Ack / Escalate / Resolve (role-gated)
     │    ├─ Break-glass (Primary/Full)
     │    └─ Evidence pack browse
     ├─ SETUP ………………… contacts · verify · priority · Panic Quiet · delays (Primary/Full)
     ├─ EVIDENCE / RETENTION … ops vs indefinite layers
     └─ AUDIT ………………… append-only lifecycle + break-glass

Cross-links (no permanent mutation from SOS):
 ├─ FS-001 Location
 ├─ Family Chat / Quran
 ├─ Modes / ST / App / Web / Camera — chips only (“does not block SOS”)
 └─ Instant Lock — SOS still reachable
```
