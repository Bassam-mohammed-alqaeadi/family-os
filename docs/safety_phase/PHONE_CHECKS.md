# فحوص الهاتف — سجل كل شريحة

> **القاعدة (قرار المالك 2026-10-10):** بعد كل شريحة تمسّ الهاتف فحص صغير يجريه المالك على نسخة **release** من `android_build.yml`، ببيانات اختبار موسومة، **وبلا GPS حقيقي** (موقع وهمي من خيارات المطوّر) حتى تُفتح بوابة البيانات الحقيقية بعد ش٢ وش٣ وبقرار المالك.
> **عمود «على الهاتف»** لا يُعلَّم ✅ إلا بصفّ «نجح» هنا، بتاريخ ورقم البناء.
> **لا يُكتب هنا:** بريد، رقم هاتف، معرّف عائلة، إحداثيات حقيقية، أو أي سرّ.

## التحضير (مرة واحدة)

1. **الهاتفان:** هاتف «والد» وهاتف «طفل» (أندرويد). حسابا اختبار يبدأ اسماهما بـ`TEST-`.
2. **تنزيل النسخة:** GitHub ← Actions ← «Android Build» ← آخر تشغيل أخضر ← Artifacts ← `family-os-test-release-<sha>-<run>.apk` (يبقى ٧ أيام). فكّ الضغط وثبّته.
   - إن رفض الهاتف التثبيت فوق نسخة سابقة («التوقيع مختلف»): احذف النسخة القديمة أولاً (يُفقد الإقران — متوقّع، انظر `RESUME.md` §٥).
3. **موقع وهمي على هاتف الطفل:** الإعدادات ← حول الهاتف ← اضغط «رقم الإصدار» ٧ مرات ← خيارات المطوّر ← «اختيار تطبيق الموقع الوهمي» ← تطبيق موقع وهمي من Play. اختر نقطة بعيدة عن البيت.
4. **الخادم المجاني ينام:** أول طلب بعد ١٥ دقيقة خمول قد يتأخر نحو دقيقة. اكتب ذلك في الملاحظات ولا تعدّه فشلاً.
