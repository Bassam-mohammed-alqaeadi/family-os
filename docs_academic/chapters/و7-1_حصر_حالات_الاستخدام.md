# و٧-١ — حصر حالات الاستخدام الكامل لنظام «عائلتي» (قائمة الاعتماد)
**التاريخ**: ٢٠ سبتمبر ٢٠٢٦ · **الحالة**: ✅ معتمدة من المالك (٢٠ سبتمبر) بإضافة UC-43

## ملخص الحصر
| البند | العدد |
|---|:-:|
| حالات الاستخدام المعيارية | **٤٣** (+٢ رفاهية بالملحق) — اكتمال القنوات الخمس ظاهرًا |
| منها عمود فقري دستوري ⭐ | ١٥ |
| منها حدثية 🔔 (G-6) | ٨ |
| علاقات تضمين | ١٩ |
| علاقات توسيع | ٨ |
| علاقات تعميم | ٦ (فاعلون: والد←أب/أم · حالات: أقفال/أوضاع/تقارير/قرآن/تعليم) |
| تغطية الرحلات | ٧٣/٧٣ ✅ (كل رحلة معينة لحالة) |

## خطة الرسم بعد اعتمادك (قانون ٠: مخطط عام + مخطط لكل مجال)
١ مخطط عام (الفاعلون الخمسة × المجالات الخمسة كحزم) + ٥ مخططات تفصيلية (مجال لكل مخطط بعلاقاته كاملة) + ٤٢ جدول وصف حالة بنسق المرجع (اسم/فاعل/شرط مسبق/مسار أساسي/بدائل/شرط لاحق).

**⏳ بوابة المالك**: اعتمد القائمة (أو اطلب دمجًا/فصلًا/إضافة) ثم أرسم.
