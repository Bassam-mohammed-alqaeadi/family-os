# و٧-٢ — جداول وصف حالات الاستخدام (بنسق المرجع) — المجالان ١ و٢
**الاصطلاح**: كل حالة توصف بجدول «البند/الوصف» بنفس نسق المرجع الزراعي · المصادر: الرحلات (JRN) + سجل السياسات (40) + أحكام (ADR)

---

## جدول وصف UC-01 — إنشاء الحساب والعائلة
| البند | الوصف |
|---|---|
| اسم الحالة | إنشاء الحساب والعائلة |
| الفاعل الأساسي | الأب (OWNER) |
| الفاعلون المشاركون | — |
| الشرط المسبق | تحميل التطبيق لأول مرة، لا حساب موجود |
| الهدف | حساب موثق وعائلة منشأة جاهزة للربط |
| المسار الأساسي | ١) إدخال البيانات ٢) التحقق من الهوية «include» ٣) تهيئة ملف العائلة الأول «include» ٤) الوصول للوحة الرئيسية |
| المسارات البديلة | أ) «extend»: تجربة النظام ببيانات تجريبية قبل الربط (UC-02) إذا لم يكن الابن حاضرًا |
| الشرط اللاحق | عائلة قائمة بمالك واحد (قيد قاعدة البيانات: مالك واحد لكل عائلة) |
| القوانين الحاكمة | schema: فهرس فريد OWNER لكل عائلة · G-3 لغة إنسانية |
| التتبع | JRN-FAT-01، JRN-FAT-03 |

## جدول وصف UC-03 — ربط جهاز ابن ⭐
| البند | الوصف |
|---|---|
| اسم الحالة | ربط جهاز ابن |
| الفاعل الأساسي | الأب |
| الفاعلون المشاركون | الابن (موافقة صريحة) |
| الشرط المسبق | عائلة قائمة + جهاز الابن متاح |
| الهدف | جهاز مربوط بشفافية كاملة وقيمة أولى ظاهرة للأب |
| المسار الأساسي | ١) توليد رمز الاقتران «include» ٢) إدخال الرمز على جهاز الابن ٣) عرض الشفافية وموافقة الابن «include» — يرى ماذا سيُراقب ٤) فحص صحة الجهاز «include» ٥) تسجيل في سجل التدقيق «include» |
| المسارات البديلة | أ) انتهاء صلاحية الرمز ← توليد جديد ب) رفض الابن ← إشعار الأب وفتح حوار |
| الشرط اللاحق | جهاز نشط في لوحة العائلة بحالة صحية معلومة |
| القوانين الحاكمة | مبدأ «حماية بلا خداع» — لا مراقبة خفية أبدًا · UF-01 |
| التتبع | JRN-FAT-02، JRN-CHD-01 |

## جدول وصف UC-04 — دعوة الأم وتحديد التفويض ⭐
| البند | الوصف |
|---|---|
| اسم الحالة | دعوة الأم وتحديد مستوى التفويض |
| الفاعل الأساسي | الأب (حصريًا — دعوة الأعضاء للمالك وحده) |
| الفاعلون المشاركون | الأم (تقبل الدعوة) |
| الشرط المسبق | عائلة قائمة، الأم غير عضو بعد |
| الهدف | الأم عضو بمستوى يحدده الأب |
| المسار الأساسي | ١) إرسال الدعوة ٢) اختيار المستوى «include»: ① مطّلعة / ② مشاركة (افتراضي) / ③ كاملة ٣) قبول الأم ٤) تسجيل تدقيق «include» |
| المسارات البديلة | أ) «extend»: تعديل المستوى لاحقًا من شاشة الصلاحيات ب) انتهاء الدعوة ← إعادة إرسال |
| الشرط اللاحق | أم فعالة بصلاحيات مستواها؛ واجهة مضاد العبث غائبة عنها كليًا (ADR-035-b) |
| القوانين الحاكمة | وثيقة ٢٠ (الجدول الملزم) · R-2, R-3 · ADR-035/035-b |
| التتبع | JRN-FAT-04، JRN-MOT-01 |

## جدول وصف UC-12 — طلب الاستغاثة (SOS) ⭐🔔
| البند | الوصف |
|---|---|
| اسم الحالة | طلب الاستغاثة |
| الفاعل الأساسي | الابن |
| الفاعلون المشاركون | الوالد (مستقبل)، الجد (مستقبل مشاهدة) |
| الشرط المسبق | **لا شيء** — تعمل بلا إنترنت، بوقت منتهٍ، باشتراك منتهٍ |
| الهدف | وصول البلاغ لكل الأوصياء خلال ثوانٍ |
| المسار الأساسي | ١) ضغطة ٣ ثوانٍ ٢) بث الموقع والصوت «include» ٣) اختراق كل الأقفال والوضع الصامت «include» (P-4) ٤) خريطة حية عند المستقبلين |
| المسارات البديلة | أ) لا شبكة ← إرسال عبر أي قناة متاحة فور عودتها مع طابع زمني |
| الشرط اللاحق | بلاغ نشط حتى يغلقه الوالد؛ كل شيء في سجل التدقيق |
| القوانين الحاكمة | **P-4** (فوق كل بوابة) · قناة مجانية دستوريًا للأبد |
| التتبع | JRN-CHD-03، JRN-FAT-09، JRN-MOT-05 |

## جدول وصف UC-15 — محافظ التطبيقات (ق-٢) ⭐
| البند | الوصف |
|---|---|
| اسم الحالة | إدارة محافظ التطبيقات |
| الفاعل الأساسي | الأب |
| الفاعلون المشاركون | الابن (يرى محافظه في «محافظ تطبيقاتي») |
| الشرط المسبق | جهاز ابن مربوط بتطبيقاته مجرودة |
| الهدف | لكل تطبيق محفظة وقت مستقلة بقواعد الأب |
| المسار الأساسي | ١) استعراض تطبيقات الابن ٢) محفظة وقت لكل تطبيق «include» ٣) قفل تلقائي عند نفاد الرصيد «include» ٤) تدقيق «include» |
| المسارات البديلة | أ) «extend»: UC-43 الفتح المشروط — تطبيق مقفول يُفتح بإنجاز شرط الأب ب) حظر صلب ← لا يفتحه إلا الأب |
| الشرط اللاحق | قواعد نافذة على الجهاز حتى بلا اتصال (آخر سياسة مزامنة) |
| القوانين الحاكمة | ق-٢ (أحكام أ-د) · قرار: الابن لا يتجاوز حدود الأب أبدًا |
| التتبع | JRN-FAT-16، JRN-CHD-02 |

## جدول وصف UC-17 — القفل الفوري ⭐
| البند | الوصف |
|---|---|
| اسم الحالة | القفل الفوري |
| الفاعل الأساسي | الوالد (أب دائمًا؛ أم في المستوى الكامل) |
| الشرط المسبق | جهاز ابن نشط |
| الهدف | إيقاف لطيف فوري (العشاء، النوم…) |
| المسار الأساسي | ١) زر القفل ٢) تأكيد ٣) شاشة هادئة عند الابن مع السبب ٤) إعفاء المحادثة/القرآن/الاستغاثة «include» ٥) تدقيق «include» |
| المسارات البديلة | أ) «extend»: تعارض — الأم قفلت والأب فتح ← **الأب يفوز** والحدث مسجل للطرفين (ADR-035) ب) قفل بمؤقت ← فتح تلقائي |
| الشرط اللاحق | جهاز مقفول عدا المعفيات؛ فتح بيد الأب أو المؤقت |
| القوانين الحاكمة | ADR-035 · P-4 (المعفيات) · UF-09 |
| التتبع | JRN-FAT-18 |

## جدول وصف UC-19 — البت في طلب الوقت الإضافي ⭐
| البند | الوصف |
|---|---|
| اسم الحالة | البت في طلب وقت إضافي |
| الفاعل الأساسي | الوالد (مشاركة+) |
| الشرط المسبق | طلب معلق من الابن (UC-18) |
| الهدف | قرار خلال دقيقة |
| المسار الأساسي | ١) إشعار بالطلب والسبب ٢) قرار خلال دقيقة «include» ٣) منح ≤ السقف الفعال (افتراضي ٣٠ د) ٤) فتح فوري عند الابن |
| المسارات البديلة | أ) «extend»: **تجاوز السقف — الأب حصرًا** (ADR-039) ب) رفض ← رسالة لطيفة بالسبب ج) لا رد ← تذكير ثم انتهاء مهذب |
| الشرط اللاحق | رصيد محدث أو رفض مسبب؛ الكل مسجل |
| القوانين الحاكمة | **ADR-039** (السقف يشمل الأم الكاملة) · وثيقة ٢٠ · UF-05 |
| التتبع | JRN-MOT-07، JRN-CHD-06 |

## جدول وصف UC-20 — معالجة محاولة تحايل 🔔
| البند | الوصف |
|---|---|
| اسم الحالة | معالجة محاولة تحايل |
| الفاعل الأساسي | الأب (حصريًا — السطح غائب عن الأم كليًا ADR-035-b) |
| الشرط المسبق | النظام كشف محاولة (حذف تطبيق، تغيير وقت، إيقاف خدمة…) |
| الهدف | فهم المحاولة والتصرف تربويًا |
| المسار الأساسي | ١) 🔔 تنبيه فوري للأب ٢) تفاصيل المحاولة ٣) خيارات متدرجة (حوار/تشديد/تجاهل) ٤) تدقيق «include» |
| المسارات البديلة | أ) محاولات متكررة ← تصعيد تلقائي بقاعدة أب |
| الشرط اللاحق | حالة الجهاز معلومة؛ لا شيء يُخفى عن السجل |
| القوانين الحاكمة | ADR-035-b · فلسفة «حوار لا عقاب» (JRN-FAT-31) |
| التتبع | JRN-FAT-19 |

## جدول وصف UC-43 — الفتح المشروط للتطبيقات (القناة الخامسة) ⭐
| البند | الوصف |
|---|---|
| اسم الحالة | الفتح المشروط للتطبيقات |
| الفاعل الأساسي | الابن (ينجز الشرط) |
| الفاعلون المشاركون | الأب (يضع الشرط) |
| الشرط المسبق | تطبيق مقفول بشرط أب («أنجز واجبك أولًا») |
| الهدف | تحفيز حقيقي: الإنجاز يفتح المرغوب |
| المسار الأساسي | ١) الابن يرى الشرط على بطاقة التطبيق ٢) ينجز (واجب/ورد/مهمة) ٣) تحقق تلقائي أو اعتماد أب ٤) فتح المحفظة |
| المسارات البديلة | أ) إنجاز جزئي ← يبقى القفل برسالة تشجيع |
| الشرط اللاحق | القناة الخامسة من قنوات الكسب الدستورية عاملة (ع-٣) |
| القوانين الحاكمة | ع-٣ (القنوات الخمس محمية) · ق-٢ |
| التتبع | JRN-FAT-16، JRN-CHD-07 |
