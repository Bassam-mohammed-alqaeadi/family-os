## ٤ — حصر أسهم الفاعلين (منضبط سلفًا لمنع العشوائية)
- **الأب**: ٣٠ سهم أساسي (كل الفقاعات) — نمط الحملة
- **الابن**: ٤ أسهم باهتة: ز٩ (يستلم المهمة)، ز١٠ (يؤكد الإنجاز)، ح١٤ (يستلم المحتوى)، ح١٨ (يستلم الهدية) + تعليق «مستلم المهام والمحتوى والهدايا — ومصدر تأكيد الإنجاز»
- **الأم**: ~١٣ سهم موروث 👥 (ز١-ز٨، ز١٠، ح٣، ح٧، ح١٥-ح١٧، ح١٩) + تعليق «ترث التواصل والمتابعة — الاستوديو الإنشائي حصري 🔒»
- **العقل (AI)**: ٨ أسهم مساندة: ز١١، ح٤، ح٦، ح٨-ح١٢ + تعليق «يولّد ويقترح — والأب يعتمد (ADR-033)»

## ٥ — تسلسل التنفيذ والتدقيق الذاتي (بعد الاعتماد)
1. توليد اللوحة عبر (uc_lib) بالمواضع أعلاه — عمود الفقاعات x=١٠٦٠، الفرعيات x=٦٢٠
2. **تدقيق آلي فوري**: عدّ `<ellipse>` = ٣١+١٦ فرعية ✓، عدّ «include» = ١٦ ✓، «extend» = ١ ✓
3. فحص بصري: لا تداخل نصوص (فارق ٨٠-٨٥ نقطة بين الفقاعات)
4. دفع (commit+push) برسالة موثقة ← عرض على المالك ← بوابة
5. عند الاعتماد: م٥ (العقل والوكيل — ١٤ عملية) تُخطط بنفس النموذج

**⏳ البوابة**: كلمة «نفذ» تطلق الرسم بهذه المواصفات حرفيًا.
