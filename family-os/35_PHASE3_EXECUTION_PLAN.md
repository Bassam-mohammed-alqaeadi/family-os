# 🗺️ ٣٥ — خطة العمل المفصلية للمرحلة القادمة (المرحلة ٣: بروفايل الابن + بقايا التوجيهات)

> 🧭 حالة هذا الملف: **خطة معتمدة للنقاش — بُنيت على فحص فعلي للكود في ١٧ سبتمبر ٢٠٢٦، كل رقم فيها مقيس لا مُخمَّن**
> المرجع: الوثيقة ٣٢ (البنود المتبقية) + الدستور ٣٣ + قرارات ج٢ (٣٤)

## أولًا: جرد الواقع (ما كشفه الفحص الآن)

| الشاشة | حالتها المقيسة | ما ينقصها حسب توجيهاتك |
|---|---|---|
| FAT-012 قائمة الأبناء | زر «+ إضافة ابن» في **ذيل** الشاشة | ب-١: نقله لأعلى مقابل «أبنائي» |
| FAT-013 البروفايل | ٣٩٠٧ حرفًا: أزرار اتصال/رسالة/خريطة + بطاقة وقت الشاشة | ب-٥/٦/٧: لوحة بيانية بدل الأزرار، حذف بطاقة وقت الشاشة، تخصيص الصورة/الخلفية/الاسم |
| FAT-014 الخريطة | فيها pin لكن **النقطة عامة** | ب-٦: أيقونة الابن 🦁 هي العلامة |
| FAT-015/016/017 | ٣ شاشات مواقع منفصلة | ب-٣: أيقونة موحدة + سجل يُدمج |
| FAT-069 تقرير الاستخدام | ١٤٨٥ حرفًا، **بلا رسم بياني** | أد-١٨: رسمه ينتقل لأعلى البروفايل |
| ب-٢ إعدادات مشتركة | **غير موجودة إطلاقًا** | بناء كامل من الصفر |

**وخارج نطاق هذه المرحلة (يُقاس لاحقًا):** ورشة الإعدادات العميقة (فلترة/رقابة/تقرير أسبوعي/تركيز/قرآن جزء عم) + تبويب العائلة (عل-١...٧) — لكل منهما مرحلة مستقلة بعد هذه.

## ثانيًا: الخطة المفصلية — ٥ حزم × تحقق إلزامي بعد كل حزمة

### 📦 الحزمة ١ — رأس تبويب «أبنائي» (ب-١ + ب-٢)
**البنود:** نقل زر الإضافة لأعلى مقابل العنوان + بناء «الإعدادات المشتركة» من الصفر.
1. FAT-012: صف علوي `عنوان أبنائي ← [+ إضافة ابن]` وحذف الزر السفلي.
2. بطاقة «⚙️ إعدادات مشتركة لكل الأبناء» تحت القائمة تفتح ورقة (sheet):
   - اختيار من تشمل (الكل / أبناء محددون).
   - السياسات القابلة للتعميم: الحد اليومي، وقت النوم، فلترة الويب، حظر تطبيق.
   - **تطبيق الحكم د الموقّع:** عند التعميم تُعرض قائمة «استثناءات فردية نشطة» (الفردي يغلب) — بيانات `S.sharedPolicies` الموجودة أصلًا في الحالة منذ المرحلة ٢.
**التحقق:** الزر أعلى الشاشة + الورقة تعمل + قائمة الاستثناءات تظهر عند وجود تعارض + 130/130.

### 📦 الحزمة ٢ — قلب المرحلة: إعادة بناء رأس البروفايل (ب-٦ + ب-٧ + أد-١٨)
**البنية الجديدة لرأس FAT-013 (من أعلى لأسفل):**
1. **البطاقة البطاقية (Hero):** خلفية قابلة للتخصيص + صورة/أيقونة الابن + الاسم والعمر.
2. **اللوحة البيانية المصغرة** (بدل أزرار اتصال/رسالة): ٤ خلايا أنيقة — 🔋 البطارية ٨٤٪ · 📶 الاتصال ممتاز · 📍 المكان الحالي · ⏱ محفظته الكلية. (الاتصال/الرسالة ينتقلان لأيقونتين صغيرتين في زاوية البطاقة — لا يُحذفان لأنهما قناة تواصل، توجيهك كان «استبدال موقعهما البارز»).
3. **رسم تقرير الاستخدام** (من FAT-069): أعمدة الأسبوع مصغرة مكان بطاقة الاتصال القديمة — نبنيه SVG داخليًا (لا مكتبات خارجية).
4. **حذف بطاقة «وقت الشاشة اليوم»** وبديلها المدروس: سطر واحد داخل اللوحة البيانية «اليوم: ٢س ١٤د من ٤س» + زر «+وقت» الذكي الموجود (يستدعي نافذة الحكم جـ) — فلا نفقد الوظيفة التي يستعملها الأب يوميًا.
**التحقق:** لا أزرار كبيرة قديمة + اللوحة بخلاياها الأربع + الرسم يظهر + بطاقة وقت الشاشة القديمة اختفت + زر «+وقت» ما زال يعمل بنافذة التعارض.

### 📦 الحزمة ٣ — تخصيص هوية الابن (ب-٥)
1. زر ✏️ على البطاقة يفتح ورقة «تخصيص ملف خالد»:
   - تغيير الاسم (حقل نصي يحدّث KIDS[0].n في كل الشاشات).
   - اختيار الصورة: شبكة أفاتارات (🦁🐯🦊🐼...) + خيار «صورة من الجهاز» (محاكاة).
   - اختيار خلفية البطاقة: ٦ تدرجات جاهزة.
2. الحفظ ينعكس فورًا: البطاقة + قائمة الأبناء + علامة الخريطة.
**التحقق:** تغيير الاسم يظهر في FAT-012 وFAT-013 معًا + تغيير الأفاتار يظهر على الخريطة (الحزمة ٤).

### 📦 الحزمة ٤ — المواقع الموحدة (ب-٣ + ب-٦ خريطة)
1. علامة الخريطة في FAT-014 وبطاقة الموقع بالبروفايل = **أفاتار الابن نفسه** داخل الدبوس (المتغير من الحزمة ٣).
2. أيقونة واحدة «📍 الموقع والأمان» في بروفايل الابن تفتح FAT-014، وداخلها ترتيب منطقي: الخريطة الحية ← المناطق الآمنة (FAT-016/017) ← **سجل المواقع مدمجًا** (محتوى FAT-015 يظهر كقسم داخلي).
3. FAT-015 تُوسم noHub (النمط الآمن المجرب) — الشاشة باقية والوصول من الدمج.
**التحقق:** الأفاتار في العلامة + المسار الموحد يعمل بالتنقل الفعلي + FAT-015 خارج الشبكات + 130/130.

### 📦 الحزمة ٥ — التحقق البصري الشامل + الختم
1. الفحص الآلي الكامل (النمط المعتاد: محاكاة + عد + قنوات).
2. **درس المرة الماضية:** فحص «منظور المستخدم» — أرندر البروفايل كاملًا وأتأكد أن كل عنصر وعدت به موجود في HTML الناتج فعلًا، وأصطاد أي «منطق بلا واجهة».
3. تحديث الوثيقة ٣٢ (ب-١/٢/٣/٥/٦/٧ + أد-١٨ ← ✅) + محضر 31A + عرض المعاينة الحية عليك للمقارنة.

## رابعًا: قواعد التنفيذ الملزمة (كما رسّخناها بالدم 😄)

1. نسخة احتياطية قبل كل حزمة + حارس عدّ الشاشات ١٣٠ قبل أي حفظ.
2. أناكر مُتحقق من تفرّدها (count==1) وإلا لا حفظ.
3. `node --check` + محاكاة بعد كل حزمة — لا انتقال لحزمة والسابقة فيها ❌.
4. القنوات الخمس تُفحص في كل حزمة.
5. كل شيء إضافي — لا حذف شاشات، noHub فقط.
6. الختام دائمًا: فحص منظور المستخدم البصري لا الاكتفاء بالمنطق.
