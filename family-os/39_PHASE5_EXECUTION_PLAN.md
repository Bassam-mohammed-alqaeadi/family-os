## ثانيًا — قراران تصميميان أعرضهما قبل التنفيذ (توصيتي مرفقة — سكوتك عنهما في «نفذ» = موافقة على التوصية)

**قرار أ — عل-٧ (مهمة للأم)**: عندما يُسند الأب مهمة لنوال، **لا مكافأة دقائق** (الدقائق عملة الأبناء وأجهزتهم) — بل تظهر عندها كـ«طلب مساعدة 🤝» بإشعار لطيف، ويُشكر إنجازها في لحظات العائلة. هذا يحفظ نقاء نظام المكافآت من التحول لعلاقة مالية بين الزوجين.

**قرار ب — عل-٤ (اتصال الابن)**: زر الاتصال عند الابن يفتح **جهات اتصال الهاتف الأساسي** (نص بندك حرفيًا) — لكن تظهر فوقها لافتة رقيقة «جهات العائلة المعتمدة أولًا». في النموذج: محاكاة فتح تطبيق الهاتف بورقة تعرض جهات الاتصال. (التنفيذ الفعلي في Flutter عبر intent نظام التشغيل).

## ثالثًا — الحزم (٥ حزم)

### حزمة ١ — الأم عضو كامل في تبويب العائلة (عل-١)
- رأس FAT-021: بطاقة «إدارة العائلة» فيها نوال 🌸 (عضو نشط · صلاحيتها الحالية) + زر «⚙️ الصلاحيات» → FAT-031 القائمة + زر «+ إضافة عضو» (دعوة QR كالأجهزة)
- محادثة نوال الفردية تُضاف للقائمة (عل-٢ جزئيًا) وفرع W==='mother' في FAT-022
- تحقق: القائمة تعرض نوال + فتح محادثتها يعمل + رابط الصلاحيات يقود لوجهته

### حزمة ٢ — إنشاء المحادثات + إعداداتها (عل-٢ + عل-٣)
- FAT-021: زر «+ محادثة جديدة» → ورقة اختيار: العائلة كاملة / نوال فقط / ابن محدد (٣ رقاقات أبناء)
- FAT-022: أيقونة ⚙️ في رأس أي محادثة → ورقة «إعدادات المحادثة» بأسلوب واتساب: ٤ خلفيات + ٣ ثيمات فقاعات، تُحفظ لكل محادثة (S.chatPrefs[chatId]) وتنعكس على فقاعات المحادثة فورًا
- تحقق: إنشاء محادثة يفتحها + تغيير خلفية نوال لا يغيّر خلفية خالد (عزل لكل محادثة)

### حزمة ٣ — التقويم الناضج (عل-٥ + عل-٦)
- FAT-052 (مقارنة مرجعية بتقويم ناضج): شبكة شهر مصغرة (٧×٥ SVG/grid بنقاط ملونة أيام الأحداث، اليوم مُحاط) + رقاقات فئات (🕌 دينية · 🎂 مناسبات · 🏫 دراسة · ⚽ نشاط) تصفّي القوائم + بقاء مواقيت الصلاة واليوم/الأسبوع
- FAT-053 إعادة نظر: إضافة «المكان 📍» (اختياري) + «تذكير قبل» (وقتها/١٥ د/ساعة/يوم) + فئة الحدث + «يخص» تشمل **نوال** والجميع + زر الحفظ يضيف الحدث فعليًا لـS.events فيظهر في FAT-052 فورًا
- تحقق: حدث جديد يظهر في التقويم بلونه وفئته + التصفية بالفئة تعمل

### حزمة ٤ — المهام لأي شخص أو للأم (عل-٧) ⚠️ قناة دستورية
- FAT-054: قسم جديد «مهام نوال 🤝» (يظهر فقط إن وُجدت) + المهام الجارية تبقى حرفيًا
- FAT-055: خيار الإسناد يشمل «نوال 🌸 (الأم)» — عند اختيارها يختفي حقل مكافأة الدقائق ويحل محله سطر «تصلها كطلب مساعدة لطيف 🤝» (قرار أ)
- **تحقق مشدد قبل وبعد**: دورة مهمة ابن كاملة (إنشاء ← pending ← اعتماد ← توست إيداع الدقائق) + مهمة أم بلا دقائق
- تحقق إضافي: صفر نقاط/XP بعد التعديل

### حزمة ٥ — اتصال الابن (عل-٤) + التدقيق الشامل + الختم
- زر الاتصال عند الابن (CHD-009 ومدخله): يفتح ورقة «جهات اتصال هاتفك» — جهات العائلة المعتمدة أولًا (أبي/أمي/جدي) ثم بقية جهات الهاتف، بأسلوب تطبيق الهاتف الأساسي (قرار ب)
- التدقيق البصري الشامل: رحلة الأب (عائلة ← نوال ← محادثة جديدة ← تقويم ← حدث ← مهمة للأم) + رحلة الابن (اتصال ← جهات الهاتف)
- الختم: 32 (عل-١..٧ → ✅) + محضر ١٠ في 31A + تقرير صادق
