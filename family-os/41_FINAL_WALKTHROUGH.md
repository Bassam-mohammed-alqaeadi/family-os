# ٤١ — الجولة الختامية بالوكالة: خطة السيناريوهات المحكمة ونتائجها
**التاريخ**: ١٨ سبتمبر ٢٠٢٦ · **التفويض**: المالك — «هل يمكنك أن تقوم بهذه العملية بنفسك… يجب أن يتنفذ كل سيناريو وفق خطة محكمة وفعالة وليس قرارًا عشوائيًا»

## قواعد التنفيذ الملزمة (لا استثناء)
1. **المشي كإنسان لا كمبرمج**: لا انتقال لشاشة إلا إذا كان زر الانتقال إليها **موجودًا فعلًا في عرض الشاشة الحالية** (الشاشة + الشبكة السفلية + التبويبات + الأزرار العائمة). القفز المباشر = فشل الخطوة.
2. **لكل خطوة ثلاثية**: الفعل ← المتوقع (من المخطط الأم والعقود) ← القياس الفعلي من الكود المعروض.
3. **التفاعل حقيقي**: حيث يتطلب السيناريو ضغطة (اختيار مدة، إتمام ذكر، تدوير سؤال) تُنفذ دالتها الفعلية ويُقاس أثرها على الحالة والشاشة.
4. أي ❌ واحد = السيناريو راسب ويُصلح قبل إعلان النتيجة.

## السيناريوهات الخمسة (من الخريطة الحقيقية للروابط — لا من الافتراض)

### س١ · أب جديد يبدأ من الصفر (م١)
FAT-001 إنشاء العائلة ← FAT-002 المعالج ← FAT-003 إضافة خالد ← FAT-004 رمز الربط ← FAT-005 شرح الصلاحيات ← FAT-006 نجاح الربط 🎉
**متوقع**: كل خطوة زرها ظاهر في سابقتها؛ FAT-005 يشرح «لماذا» كل إذن؛ FAT-006 يحتفي.

### س٢ · صباح الأب — الاطمئنان بلمحة (م٢)
فتح FAT-010 ← قراءة بطاقات اليوم ← بشرى أذكار خالد تظهر عند إتمامها (تفاعل حقيقي: sayThikr حتى ١٠/١٠) ← طلب وقت معلق ← FAT-033 ← عودة ← ✨ مستشار العائلة FAT-074 (الزر العائم).

### س٣ · الأب يدير خالد (م٣+م٦)
FAT-012 ← FAT-013 ملف خالد ← أدواته من داخل الملف: وقت الشاشة/التطبيقات/الفلترة/القفل/القرآن ← FAT-064 الخارطة (تفاعل: تدوير سؤال العشاء) ← عودة للملف.
**متوقع**: كل أداة تُفتح من بطاقتها داخل الملف (قرار «الأدوات per-child»)، وكلها تتكلم عن خالد تحديدًا.

### س٤ · خالد يعيش يومه كاملًا (م٤+م٥+م٧)
CHD-004 لوحة يومي ← مهامي CHD-022 ← تعلّمي CHD-012 ← اختباري CHD-015 ← وردي CHD-025 ← «أنا» CHD-010 ← محفظتي CHD-019 (متوقع: بطاقة نافس نفسك + خزانة الشارات) ← وردي/تعلمي ← تركيز CHD-018 ← أصواته CHD-035 (متوقع: زر العودة للجلسة — الحلقة مغلقة) ← طلب وقت CHD-020 (تفاعل: اختيار ١٥ ثم ساعة — الإبراز يتبع) ← انتهاء الوقت CHD-021 (متوقع: المحادثة والقرآن لا يُقفلان) ← نجدة CHD-005 من الزر العائم (متوقع: ضغط مطول حي) ← عائلتي CHD-007 ← مرح المكالمة CHD-036.

### س٥ · الحواف والسيادة (م٨+م٩)
FAT-025 الإعدادات ← الراوتر FAT-078 (تفاعل: دليل الضبط يفتح بخطواته) ← الاشتراك FAT-057 (متوقع: تعهد الـ٣ أيام + إلغاء يؤكد الأمان الدائم) ← الخصوصية FAT-059 (تفاعل: مسار الحذف المزدوج بخطوتيه ومهلة الـ٧ أيام) ← سجل التدقيق FAT-060 ← وضع التجربة FAT-007 (من FAT-004).
**+ فحص سيادة**: بعين الابن، الشاشات الأربع الحساسة تصد.

## النتائج
**الحصيلة: ٧١/٧١ ✅ — السيناريوهات الخمسة اجتازت كاملة، صفر إخفاق.**

| سيناريو | خطوات المشي | التفاعلات الحقيقية المقاسة | النتيجة |
|---|:-:|---|:-:|
| س١ أب جديد | ٦ شاشات متتالية — كل زر موجود في سابقته | شرح «لماذا» بالأذونات، احتفاء الربط | ✅ |
| س٢ صباح الأب | لوحة اليوم ← الطلبات ← عودة ← ✨ المستشار | **إتمام أذكار خالد فعليًا (sayThikr ×٧) → بشرى البركة ظهرت عند الأب** | ✅ |
| س٣ إدارة خالد | الملف ← ١١ أداة كلها من بطاقاتها، كلها تتكلم عن خالد | **تدوير سؤال العشاء: النص تغيّر فعلًا والقديم اختفى** | ✅ |
| س٤ يوم خالد | ١٤ محطة عبر التبويبات الأربعة | **اختيار المدد (الإبراز يتبع الاختيار حصريًا)، حلقة التركيز⇄الأصوات، نجدة بالضغط المطول، انتهاء الوقت يحفظ المحادثة والقرآن** | ✅ |
| س٥ الحواف | الإعدادات ← ٥ شاشات سيادة | **دليل الراوتر فُتح بخطواته، الحذف المزدوج نُفذ خطوة خطوة (٧ أيام)، الشاشات الأربع صدّت الابن** | ✅ |

**قاعدة «المشي كإنسان» صمدت في كل خطوة**: لا انتقال واحد تم دون زر ظاهر في الشاشة السابقة (الانتقالات بالتبويبات مثبتة كأزرار التبويب الحقيقية).
