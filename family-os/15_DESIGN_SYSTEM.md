# ما الذي يجعل FamiSafe ناجحًا بصريًا؟

درستُ واجهته فوجدت **سبعة قرارات** تصنع إحساسه:

| # | القرار | الأثر |
|---|---|---|
| ١ | **بنفسجي غني كهوية كاملة** | دافئ وودود — ليس أمنيًا ولا طبيًا |
| ٢ | **بطاقات بيضاء عائمة على خلفية مزرقة فاتحة** | عمق وتنفّس — لا جداول مسطحة |
| ٣ | **حواف دائرية كبيرة جدًا (٢٠–٢٤)** | نعومة فورية تُشعر بالأمان |
| ٤ | **عناوين سوداء ثقيلة جدًا (٨٠٠)** | وضوح وثقة — يُقرأ بنظرة |
| ٥ | **أرقام ضخمة** (`4h 18m`) | المعلومة الأهم تُرى قبل القراءة |
| ٦ | **لمسة نعناعية مقابل البنفسجي** | حيوية تكسر رتابة اللون الواحد |
| ٧ | **شخصية كرتونية للطفل** | إنسنة — الابن ليس «جهازًا مراقَبًا» |

> **الخلاصة:** الدفء لا يأتي من الألوان الدافئة وحدها — **بل من النعومة والعمق والحيوية**. FamiSafe بنفسجي بارد الطيف، لكنه **يبدو دافئًا** لأن حوافه ناعمة وبطاقاته عائمة.

# القسم الأول: الألوان

## 🟣 الهوية — بنفسجي عائلي دافئ

| الرمز | القيمة | الاستخدام |
|---|---|---|
| `--primary-700` | `#5B3FD0` | ضغط · نصوص على فاتح |
| `--primary-600` | `#6C4BD8` | نهاية التدرّج |
| `--primary-500` | **`#7C5CE6`** | **اللون الأساسي** |
| `--primary-400` | `#8B6FF0` | بداية التدرّج |
| `--primary-100` | `#EDE7FF` | خلفيات ناعمة |
| `--primary-50` | `#F6F3FF` | خلفية بطاقات مميزة |

**التدرّج الأساسي:** `linear-gradient(135deg, #8B6FF0, #6C4BD8)` — يُستخدم في بطاقة الابن النشط والأزرار الأساسية.

## 🌿 اللون المكمّل — نعناعي

| الرمز | القيمة | الاستخدام |
|---|---|---|
| `--mint-500` | **`#00D9A3`** | **أشرطة التقدّم · النجاح · اللمسات الحيوية** |
| `--mint-100` | `#D4FBF0` | خلفيات نجاح |

> **هذا اللون هو سر الحيوية.** البنفسجي وحده يصبح رتيبًا؛ والنعناعي يكسره **في اللحظات الإيجابية فقط**: شريط الوقت المتبقي · علامة الإنجاز · مؤشر «كل شيء بخير».

## 🧡 اللمسة الدافئة

| الرمز | القيمة | الاستخدام |
|---|---|---|
| `--amber-500` | `#FFB547` | التحذير · الشارات · الباقة المدفوعة |
| `--amber-100` | `#FFF4DE` | خلفية التنبيه اللطيف |

## 🚦 ألوان الحالة

| | القيمة | المعنى |
|---|---|---|
| 🟢 طبيعي | `#00D9A3` | كل شيء على ما يرام |
| 🟡 انتبه | `#FFB547` | يستحق نظرة |
| 🔴 تدخّل | `#FF5A5F` | يحتاج فعلًا الآن |

> **⛔ قاعدة الأحمر تبقى:** للخطر الحقيقي فقط. والأحمر المختار `#FF5A5F` **مرجاني دافئ** لا قرمزي صارخ — ينبّه دون أن يُفزع.

## 🌫️ المحايدة

| الرمز | فاتح | داكن |
|---|---|---|
| `--bg` | **`#F5F6FA`** ← مزرقة لا رمادية | `#14161F` |
| `--surface` | `#FFFFFF` | `#1E2130` |
| `--text` | **`#1A1D2E`** ← أزرق داكن لا أسود | `#F0F1F5` |
| `--text-2` | `#8A8FA3` | `#9298AD` |
| `--border` | `#EDEEF5` | `#2A2E3F` |

> **تفصيل دقيق يصنع فرقًا:** الخلفية `#F5F6FA` **مزرقة قليلًا** لا رمادية محايدة. هذا ما يجعل البطاقات البيضاء **تطفو** بدل أن تلتصق. والنص `#1A1D2E` أزرق داكن لا أسود — **أكثر دفئًا للعين**.

# القسم الثاني: الخطوط

**الخط:** `IBM Plex Sans Arabic` · البديل `Cairo`

## السلّم — بأوزان ثقيلة كما في FamiSafe

| المستوى | الحجم | الوزن | مثال |
|---|:-:|:-:|---|
| `hero` | ٣٦ | **٨٠٠** | `٤ س ١٨ د` |
| `h1` | ٢٤ | **٨٠٠** | لوحة اليوم |
| `h2` | ١٩ | **٧٠٠** | الموقع المباشر |
| `h3` | ١٦ | ٧٠٠ | خالد — ١٤ سنة |
| `body` | ١٥ | ٤٠٠ | النص الأساسي |

> **الوزن ٨٠٠ للعناوين ليس مبالغة — إنه توقيع FamiSafe البصري.** العنوان الثقيل على خلفية بيضاء نظيفة **يُقرأ في جزء من ثانية**، وهو ما يجعل اللوحة تُفهم في ٥ ثوانٍ.

## الظلال — ناعمة وواسعة الانتشار

```
shadow-card:  0 2px 12px  rgba(26,29,46,.05)
shadow-float: 0 8px 28px  rgba(26,29,46,.08)
shadow-brand: 0 8px 24px  rgba(124,92,230,.28)   ← للعناصر البنفسجية
```

> **`shadow-brand` تفصيل احترافي:** الزر البنفسجي يُلقي ظلًا **بنفسجيًا** لا رماديًا. هذا ما يجعله يبدو **مضيئًا** لا مُلصقًا.

## 🎯 تشريح البطاقة القياسية

```
┌────────────────────────────────────┐
│  الموقع المباشر        التفاصيل ‹  │ ← عنوان ١٩/٧٠٠ + رابط بنفسجي
│                                     │
│  ┌───────────────────────────────┐ │
│  │        [ المحتوى ]             │ │ ← حافة ١٦ داخلية
│  └───────────────────────────────┘ │
│                                     │
│  📍 حي النرجس — الرياض             │ ← سطر ١٣ رمادي
│  🕐 اليوم ٨:٣٥ م                   │
└────────────────────────────────────┘
   حافة ٢٠ · حشو ١٨ · ظل ناعم
```

**كل بطاقة في التطبيق تتبع هذا الهيكل.** التكرار هنا **ميزة لا عيب** — المستخدم يتعلّم القراءة مرة واحدة.
