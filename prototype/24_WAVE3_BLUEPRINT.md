# 🌊 24 — مخطط الموجة الثالثة «موجة الذكاء والعمق» — الوثيقة الرسمية
**١٤ سبتمبر ٢٠٢٦ · الحالة: مكتملة التخطيط ١٠٠٪ ✅ · المرجع: ADR-020 + ADR-021**

> بهذه الوثيقة **يكتمل تخطيط الموجات الثلاث كلها** — شرط ADR-020 مستوفى.
> ٢٤٠ خدمة، ٦٤ رحلة، ١١٤ شاشة — بلا مجهول واحد.

---

## ١) الملخص التنفيذي

| البند | القيمة |
|---|:-:|
| خدمات الموجة | ٥٨ (١٨ P0 · ٢٠ P1 · ١٩ P2 · ١ P3) — تغطية **١٠٠٪** بالمدقق الرسمي |
| نطاق ٣أ (تفصيل كامل) | P0+P1 = ٣٨ خدمة |
| نطاق ٣ب (نائب — بعد الإطلاق) | P2+P3 = ٢٠ خدمة عبر شاشتين نائبتين (FAT-075 · CHD-031) |
| رحلات جديدة | **١٣** (أب ٨ · أم ١ · ابن ٤) → المجموع ٦٤ |
| شاشات جديدة | **١٩** (والدان ١٢ · ابن ٧) → المجموع ١١٤ |
| محرّكات بلا شاشة جديدة | ٥ روابط: AIC-018←CHD-017 · AIC-020←CHD-014/016 · AIC-021←FAT-043/044 |
| التدقيق | validate.py (الوضعان) + check_consistency + العرضي المخصص (٩ فحوص) = **صفر أخطاء** |

**لماذا ١٩ شاشة فقط لـ٥٨ خدمة؟** مبدأ «التصنيف قبل التخطيط» (ADR-021): الموجة ٣ أغلبها
محرّكات تشغّل شاشات قائمة وامتدادات وخدمات خلفية صامتة — التطبيق يبقى نحيفًا وفق
«بطاقة واحدة، قرار واحد». هذه ميزة تنافسية عالمية لا نقصًا.

## ٢) التصنيف الرباعي — مصير كل خدمة (٥٨/٥٨)

### م — محرّكات لشاشات قائمة (٥)
| الخدمة | تشغّل |
|---|---|
| S-AIC-018 المعلم الذكي | SCR-CHD-017 معلمي الذكي |
| S-AIC-020 تصحيح الواجبات | SCR-CHD-014 واجبي + SCR-CHD-016 نتيجتي |
| S-AIC-021 توليد محتوى الاستوديو | SCR-FAT-043 المخرجات + SCR-FAT-044 المعاينة |

### ج — شاشات جديدة (التفصيل في §٣)
كتل: الرقابة الذكية، المنصات، التقارير، الدائرة الخارجية، القرآن، التكيفي، العقل المتقدم.

### ت/خ — امتدادات وخلفي صامت (أمثلة حاكمة)
| الخدمة | أين يظهر أثرها |
|---|---|
| S-SEC-052 الاحتفاظ ٣٠ يومًا | خلفي — أثره في FAT-069 ويحترم زر النسيان (FAT-059) |
| S-SEC-053 الملخص البريدي | امتداد FAT-073 (نسخة بريدية من التقرير الأسبوعي) |
| S-SEC-034 كشف العامية والعربيزي | خلفي — أثره تنبيهات FAT-065 |
| S-AIC-028 اقتراحات استباقية | امتداد FAT-073 |

### ٣ب — النوّاب (٢٠ خدمة P2/P3)
- **SCR-FAT-075 «قادم قريبًا»**: فلترة الراوتر، القيادة والحوادث ×٣، مقارنة الأقران، ChoreAI، تصحيح التلاوة بالعقل، مشروع بمراحل، تحليل التلاوة، المحادثة الصوتية، **الوكيل المفوَّض الخماسي** (AIC-030..034).
- **SCR-CHD-031 «قادم لك 🎁»**: ألعاب المكالمة، الملصقات، القصص التفاعلية، الأقسام التنافسية، صوت التركيز.
