# 38 — خطة تنفيذ المرحلة ٤: ورشة الإعدادات العميقة
**التاريخ**: ١٨ سبتمبر ٢٠٢٦ · **المرجع**: 37 (جلسة القرارات — المالك وافق على كل التوصيات + الاسم «مستشار العائلة») + وثيقة 32
**الحالة**: بانتظار كلمة «نفذ» — لا تنفيذ قبلها

## القرارات المعتمدة (من 37 — كلها بالتوصية)

ق-١: وقت الشاشة = ترفيه فقط · ق-٢: فلترة بنمط Family Link + قاموس · ق-٣: ٦ مفاتيح تحايل · ق-٤: رقابة ذكية بعلم الابن · ق-٥: جلسات تركيز أب+ابن · ق-٦: جزء عم كهدية بإشعار · ق-٧: إعدادات تقرير حية · **ق-٨: «مستشار العائلة»** · ق-٩: إخطارات الأم بهوية لوحتها · ق-١٠: بنّاء إذا/فـ · ق-١١: لحظات + ألبوم + إعدادات · ق-١٢: حذف FAT-039 نهائيًا (١٣٠←١٢٩) · ق-١٣: فجوة ٩ عدّ تنازلي ٥ دقائق

## الحزم — ٦ حزم بترتيب يقلل المخاطر (الأصغر والمعزول أولًا)

### حزمة ١ — التنظيف والاسم (ق-١٢ + ق-٨) — الأوسع أثرًا نصيًا، الأبسط منطقيًا
- **حذف FAT-039 نهائيًا** من SCREENS (يتيمة مثبتة: صفر روابط). عدّ الشاشات الرسمي يصبح **١٢٩** — تحديث كل تأكيدات العدّ في المحاكاة والسجلات
- **إعادة التسمية**: «الذكاء الاصطناعي» ← «مستشار العائلة» في المواضع الواجهية (عناوين، بطاقات، توست) — **مع استثناء**: عبارات وصفية تقنية تبقى («يحلل الذكاء…» تصبح «يحلل المستشار…» حيث يحسُن لغويًا؛ استبدال سياقي لا أعمى، موضعًا موضعًا بقائمة مراجعة)
- **ي-١٢ بقية**: حذف أيقونة FAT-074 من قسم اليوم (noHub أو إزالة البطاقة من HOMES) — الوصول عبر الزر العائم ✨ فقط + إعادة ترتيب FAT-074: الترحيب أولًا، ثم القدرات مجمعة، ثم «أنت السيد 👑»
- **تحقق**: ١٢٩/١٢٩ · صفر «FAT-039» في الكود · عيّنة رندر ٥ شاشات تحمل الاسم الجديد · الزر العائم يفتح المستشار

### حزمة ٢ — أمان وقت الشاشة (ق-١ + ق-٣) — FAT-032 و FAT-038
- **FAT-032**: بطاقة تعريف «ماذا يُحسب؟» + قائمة تطبيقات بمفاتيح (يُحسب/لا يُحسب) — يوتيوب/ألعاب = يُحسب افتراضيًا؛ قرآن/تعليمي/مكالمات = لا يُحسب؛ الأب يقلب أي مفتاح (S.screenTimePolicy{countable:{appId:bool}})
- **FAT-038**: استبدال البطاقات الثابتة بـ٦ مفاتيح حقيقية (S.antiTamper{noDelete,noClockChange,noVPN,simAlert,settingsPin,bypassAlert}) وكل مفتاح معه سطر «ماذا يحدث عند التفعيل»؛ السجل يبقى
- **تحقق**: قلب مفتاح في المحاكاة يغيّر الحالة والرندر · ١٢٩/١٢٩ · القنوات الخمس

### حزمة ٣ — الفلترة والرقابة (ق-٢ + ق-٤) — FAT-036 و FAT-065
- **FAT-036**: ٣ مستويات (صارم/متوازن/مفتوح) كأزرار اختيار + بطاقة «قاموس الكلمات المحظورة» (رقاقات + إضافة) + قائمتا حظر/سماح يدويتان + بطاقة «كيف يراه الابن» (معاينة صفحة الحجب المؤدبة)
- **FAT-065 ← «الرقابة الذكية»**: تغيير الاسم والأيقونة؛ مفاتيح: تحليل البحث · تصنيف الصور · لقطة شاشة (مع منتقي «التطبيقات المشمولة» يحدده الأب) · يعمل أوفلاين؛ بطاقة «عند الاكتشاف: حفظ اللقطة + تقرير إليك» + **بطاقة الشفافية**: «خالد يعلم أن الرقابة قائمة — الحماية بلا خداع» (ق-٤)
- **تحقق**: تبديل مستوى الفلترة ينعكس · sheet منتقي التطبيقات يعمل · ١٢٩/١٢٩

### حزمة ٤ — التركيز والقرآن (ق-٥ + ق-٦) — FAT-051 و FAT-072 ⚠️ قناة كسب
- **FAT-051**: قسم «جلسات الأب المجدولة» (جلسة مذاكرة: الوقت + التطبيقات المغلقة + الابن المعني) + إبقاء قناة الانضباط الذاتي كما هي حرفيًا (rewardSelfDiscipline لا يُمس)
- **FAT-072**: بطاقة «📖 جزء عمّ — هدية تلقائية»: رقاقات سور (عيّنة ممثلة + «الجزء كاملًا»)؛ لمس سورة → توست «🎁 ستصل خالد: نصًا وتلاوة» + إشعار هدية عند الابن (سطر في CHD-025)
- **تحقق إلزامي مشدد**: دورة القرآن كاملة (خطة ← تسميع ← إيداع دقائق) + rewardSelfDiscipline يعمل قبل وبعد · ١٢٩/١٢٩

### حزمة ٥ — المستشار وأدواته (ق-٧ + ق-٩ + ق-١٠) — FAT-073 و FAT-076 و FAT-079
- **FAT-073**: بطاقة إعدادات فوق التقرير: التوقيت (الجمعة صباحًا) + الشكل (مختصر/مفصل) + ٥ مفاتيح محتوى — والتقرير المعروض تحتها يتبعها **حيًا** (S.weeklyReport{when,style,include{}})
- **FAT-076**: ترويسة بهوية لوحة الأم + شريط «أنت تشاهد ما يصل زوجتك» + زر «تعديل ما يصلها» (sheet مفاتيح)
- **FAT-079**: بنّاء «إذا/فـ»: sheet بقائمتين جاهزتين (٤ شروط × ٤ إجراءات) → قاعدة جديدة تُضاف للقواعد النشطة مع زر حذف؛ «ما لا يُفوَّض 🔒» تبقى مثبتة أسفل
- **تحقق**: إطفاء مفتاح «المواقع» يخفي قسم المواقع من التقرير المعروض · إضافة قاعدة إذا/فـ ثم حذفها · ١٢٩/١٢٩

### حزمة ٦ — اللحظات + فجوة ٩ + الختم (ق-١١ + ق-١٣)
- **FAT-086**: «ألبوم اللحظات» (شبكة ٦ لحظات: صورة رمزية + من أضافها + متى) + sheet إعدادات (من يضيف: الكل/الأبوان · إشعار عند الإضافة)
- **فجوة ٩**: modeCountdown في S؛ عند وضع مجدول: بطاقة عدّ تنازلي عند الابن (CHD-004) «🌙 وضع النوم بعد ٥ دقائق — أنهِ ما بيدك» + سطر في شاشة الأوضاع عند الأب؛ **التفعيل اليدوي من الأب يبقى فوريًا** (سلطة الأب لا تُقيد)
- **التدقيق البصري الشامل**: رحلة الأب عبر كل الشاشات المعدلة + رحلة الابن (CHD-004 العدّ التنازلي، هدية السورة) 
- **الختم**: 32 (١٣ صفًا → ✅) + محضر ٩ في 31A + تحديث العدّ الرسمي ١٢٩ في السجلات + تقرير صادق
