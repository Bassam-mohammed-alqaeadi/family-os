## ١. 🔐 القواعد السبع الحاكمة للعقود

هذه ليست توصيات — **كل عقد يخالفها مرفوض في المراجعة**.

### القاعدة ١ — `mode` و`permission_level` في كل استجابة
كل رد من الخادم يحمل سياق المُستدعي. **لا عميل يقرّر صلاحيته بنفسه.**
```json
{ "data": {...},
  "ctx": { "mode": "PARENT", "permission_level": "PARTNER", "family_id": "fam_x7k2" } }
```

### القاعدة ٢ — الاسم الصريح للابن لا يغادر حدود العائلة
داخل العائلة: `خالد`. في التحليلات والسجلات والذكاء السحابي: **`child_a7f3` فقط**.
جدول الربط `child_alias` **لا يُرسَل إلى أي خدمة خارجية إطلاقًا**.

### القاعدة ٣ — الاستغاثة لا تعتمد على شيء
`POST /sos` **لا يفحص**: الاشتراك · الباقة · حالة الاتصال · صلاحية المستدعي.
**طابور محلي + إعادة إرسال** حتى النجاح. مخزَّن على الجهاز أولًا.

### القاعدة ٤ — سجل التدقيق يُضاف ولا يُعدَّل
`audit_log` **append-only**. لا `UPDATE` ولا `DELETE` — يُفرض على مستوى قاعدة البيانات.

### القاعدة ٥ — الأذونات حالة مرصودة لا مفترضة
`device_permission` يخزّن ما هو **ممنوح فعلًا الآن**. الخادم **لا يفترض** — يقرأ.
وهذا ما يغذّي «صحة الاتصال» و«أصلح المعطّل».

### القاعدة ٦ — كل كتابة تحمل `request_id` للتكرار الآمن
الشبكة تنقطع، والعميل يعيد المحاولة. `request_id` (UUID) يمنع الازدواج.

### القاعدة ٧ — ثلاثة حقوق خارج فحص الصلاحيات
**الاستغاثة · الاتصال بالأبناء · رؤية مواقعهم** — أي وليّ أمر، بأي مستوى، بلا استثناء.
تُفحص العضوية في العائلة فقط، **لا `permission_level`**.

## ٢. 🗄️ نموذج البيانات — ١٨ جدولًا

### 🅐 الهوية والعائلة (٦)

| الجدول | الغرض | ملاحظات حاكمة |
|---|---|---|
| `account` | حساب بالبريد وكلمة المرور | ⛔ لا هاتف ولا OTP (ADR-003) |
| `family` | العائلة · `owner_account_id` | **مالك واحد فقط** |
| `member` | العضوية والدور | `role` + `permission_level` |
| `child` | ملف الابن | `alias` فريد `child_XXXX` |
| `invite` | دعوة وليّ أمر | تحمل **المستوى المقترح** |
| `pairing_token` | رمز QR | صالح **٥ دقائق** · استخدام واحد |

**`member.role`** ∈ `OWNER` · `PARENT` · `GUARDIAN`
**`member.permission_level`** ∈ `OBSERVER` · `PARTNER` · `FULL`

> `GUARDIAN` (جد/عم) **مثبَّت على `OBSERVER` ولا يُرقّى** — قاعدة من `20_MOTHER_PERMISSIONS.md`.

### 🅑 الأجهزة والأذونات (٤)

| الجدول | الغرض |
|---|---|
| `device` | الجهاز · `mode` · المصنّع · الطراز |
| `device_permission` | **حالة كل إذن الآن** + وقت آخر فحص |
| `device_health` | آخر نبضة · درجة الصحة · سبب الانقطاع |
| `mode_unlock_attempt` | 🔐 محاولات فتح وضع الوالد |

**`device.mode`** ∈ `PARENT` · `CHILD_LOCKED` · `CHILD_PREVIEW`
**`device_permission.key`** ∈ `LOCATION_FG` · `LOCATION_BG` · `ACCESSIBILITY` · `BATTERY_UNRESTRICTED` · `AUTOSTART` · `NOTIFICATIONS` · `USAGE_STATS` · `SCREEN_TIME_IOS`
**`status`** ∈ `GRANTED` · `DENIED` · `RESTRICTED_BY_OS` · `NOT_APPLICABLE`

> `RESTRICTED_BY_OS` تخدم **وضع الحماية المتقدّمة في أندرويد ١٧** — نميّز «رفض الأب» عن «منع النظام»، والرسالة تختلف.

### 🅒 الموقع والطوارئ (٤)

| الجدول | الغرض | ملاحظات |
|---|---|---|
| `location_ping` | نبضة موقع | **تُقلَّم بعد ٩٠ يومًا** |
| `geofence` | منطقة آمنة | مركز + نصف قطر |
| `geofence_event` | دخول/خروج | يغذّي التنبيهات |
| `sos_alert` | بلاغ استغاثة | ⛔ **لا يُحذف أبدًا** |

### 🅓 التواصل (٣)

| الجدول | الغرض | ملاحظات |
|---|---|---|
| `conversation` | محادثة · دائرة مغلقة | `approved_by` إلزامي |
| `message` | رسالة | **مشفّرة طرفيًا** — الخادم يخزّن التشفير فقط |
| `call_log` | سجل مكالمة | بيانات وصفية فقط — ⛔ لا تسجيل |

### 🅔 الذكاء والتدقيق (٣)

| الجدول | الغرض | ملاحظات |
|---|---|---|
| `ai_event` | حدث مرصود | **بالـ`alias` حصرًا** |
| `ai_suggestion` | اقتراح + **درجة ثقة** | يغذّي «ختم العقل» |
| `audit_log` | 🔒 **append-only** | الموافقات · تغيير الصلاحيات · الاستغاثة |

## ٣. 🌐 عقود الـAPI — ٢٤ نقطة

`Base: /v1` · `Authorization: Bearer <jwt>` · `X-Request-Id: <uuid>`

### الإعداد والهوية
```
POST   /auth/register          بريد + كلمة مرور              → S-ADM-001
POST   /auth/login                                           → S-ADM-001
POST   /families               ينشئ عائلة ويصير OWNER        → S-ADM-008
GET    /setup/progress         نسبة الاكتمال + الخطوات       → S-ADM-005
```

### ربط الابن
```
POST   /children               ينشئ ابنًا ويولّد alias        → S-ADM-014
POST   /children/{id}/pair     يصدر QR (٥ دقائق)            → S-ADM-003
POST   /pair/claim             الابن يستهلك الرمز           → S-ADM-003
DELETE /devices/{id}           فصل جهاز                     → S-ADM-018
```

### الأدوار والدعوات
```
POST   /invites                { email, permission_level }   → S-ADM-009
POST   /invites/{t}/accept                                   → S-ADM-011
PATCH  /members/{id}/level     🔒 OWNER فقط · تأكيد مزدوج    → S-ADM-010
```

### الأذونات وصحة الجهاز
```
PUT    /devices/{id}/permissions   العميل يبلّغ الحالة        → البوابات
GET    /devices/{id}/health        درجة + سبب + إجراء مقترح  → S-ADM-016
POST   /devices/{id}/heartbeat     نبضة كل دقيقتين           → S-ADM-017
```

### الموقع
```
POST   /locations/batch        دفعة نبضات (توفير بطارية)     → S-SEC-019
GET    /children/{id}/location  آخر موقع                     → S-SEC-019
GET    /children/{id}/history   سجل ٩٠ يومًا                 → S-SEC-020
POST   /geofences                                            → S-SEC-021
```

### 🚨 الطوارئ — بلا أي فحص
```
POST   /sos                    ⛔ لا اشتراك · لا صلاحية      → S-SEC-026
POST   /sos/{id}/ack           وليّ أمر اطّلع                → S-SEC-027
PATCH  /sos/{id}/resolve       إغلاق يدوي فقط               → S-SEC-026
```

### التواصل
```
GET    /conversations                                        → S-COM-001
POST   /conversations/{id}/messages                          → S-COM-002
POST   /calls/token            رمز LiveKit                   → S-COM-010
```

### الذكاء
```
GET    /suggestions            + درجة الثقة                  → S-ADM-039
POST   /suggestions/{id}/apply زر واحد · تراجع ١٠ دقائق      → S-AIC-003
```

## ٦. 🛡️ الامتثال في طبقة البيانات

| الضابط | التنفيذ |
|---|---|
| ⛔ لا `AAID` من الابن | **غير مُعلَن في Manifest** + اختبار CI يُفشل البناء |

| موافقة وليّ الأمر | صف في `audit_log` بطابع زمني — **دليلنا عند أي مراجعة** |
